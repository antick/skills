# Sources and interpretation

Research checked 2026-10-25. Recheck AICPA's current listings at assessment time;
record the version actually used and any inability to access the full guidance.
These references support a readiness review, not a claim to reproduce every
licensed examination requirement or Vanta's proprietary test catalogue.

## Primary framework sources

- [AICPA: 2017 Trust Services Criteria, with revised points of focus (2022)](https://www.aicpa-cima.com/resources/download/2017-trust-services-criteria-with-revised-points-of-focus-2022).
  Framework authority for criteria and category scope. Full download may require
  a free account. Points of focus support judgment; they are not individually
  mandatory controls. The 2022 revisions changed points of focus, not the criteria.
- [AICPA: 2022 revisions, redlined primary document](https://assets.ctfassets.net/rb9cdnjh59cm/2sK6Ih6dzy6t7aU6RQvoeD/d97a2a14609e74a1af1ce9ab0b142b69/92317096_trust_services_criteria_red-lined_version.pdf).
  Useful accessible reference for exact IDs and changes; it displays deleted as
  well as added wording, so use the clean current edition for final interpretation.
- [AICPA: SOC suite of services and linked guidance](https://www.aicpa-cima.com/resources/landing/system-and-organization-controls-soc-suite-of-services).
  Entry point for SOC 2 guidance and the **2018 SOC 2 Description Criteria with
  revised implementation guidance (2022)**. Retrieve that guidance through the
  official listing or request the organization's authorized copy when assessing
  description readiness. The full description guidance was not accessible during
  this research; the coverage prompts do not replace it.
- [AICPA testimony explaining SOC examinations and report types](https://assets.ctfassets.net/rb9cdnjh59cm/QPkoCj9ZpAtz0hqaRf0fw/afec1a0e14d230926a9a0b1c91a46e0d/testimony-on-cybersecurity-issues-affecting-health-benefit-plans.pdf).
  Type I assesses at a point in time; Type II adds operating effectiveness over
  a period. Only an independent CPA examination supplies the formal report.

The coverage index paraphrases criterion topics; evidence prompts are practical
review suggestions, not AICPA quotations or a mandated implementation checklist.
Exact technical thresholds, control frequency, sampling and retention depend on
risk, service commitments, policies, legal obligations and examination scope.
Do not claim that SOC 2 universally mandates a named vendor, annual pentest,
quarterly review, particular cipher, or fixed evidence-retention period.

## Vanta as an evidence and monitoring model

- [Vanta: automated compliance](https://www.vanta.com/products/automated-compliance).
  Describes integrations, automated checks, evidence collection and ongoing
  monitoring. This motivates checking integration health, scope and freshness;
  the skill itself is an on-demand assessment with no background monitoring.
- [Vanta: how auditors use Vanta](https://help.vanta.com/en/articles/11345844-how-will-your-auditor-use-vanta).
  Describes tests plus documents, risk/vendor/personnel evidence and independent
  auditor review. Some evidence requires manual work. Vendor terminology does
  not change the AICPA framework or turn a dashboard into an audit opinion.

When exports are available, assess failed checks, passing checks, disabled tests,
excluded resources, accepted exceptions, stale integrations and evidence history.
Reconcile contradictions with actual scoped resources. Do not assume access to
Vanta or claim identical detection coverage. Do not make up test IDs, integrations,
API endpoints, test counts, or an audit pass probability.
