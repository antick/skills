# Simplified Technical English

Follow ASD-STE100 Simplified Technical English in all explanations, instructions, and reports. Preserve technical accuracy and exact code identifiers.

## Writing rules

- Use dictionary-approved words with their approved meanings and parts of speech.
- Use technical names and technical verbs as permitted by ASD-STE100. Use the same term for the same concept.
- Write instructions in the active voice. Use the imperative for actions that the reader must do.
- Use a maximum of 20 words in each procedural sentence and 25 words in each descriptive sentence.
- Give one instruction in each sentence, unless actions occur at the same time.
- Put conditions before the related instruction. Put steps in the order that the reader must do them.
- Use short sentences and clear subjects. Use one topic in each paragraph.
- Rewrite unclear sentences instead of replacing individual words when a replacement would change the meaning.

## Technical accuracy

Keep code, identifiers, commands, paths, API names, literal values, and quoted source text exact. Apply STE to the surrounding prose.
Explain necessary technical terms when the reader needs a definition.
Preserve facts, units, limits, conditions, evidence, and uncertainty when you simplify text.

## Final check

Review sentence length, word choice, consistent terms, and the order of instructions. Compare the result with the source for accuracy.
Use the [official ASD-STE100 standard](https://www.asd-ste100.org/) for writing rules and dictionary checks. Use the edition specified by the user when provided.
Check uncertain words against the dictionary. Claim full compliance only after checking the applicable rules and dictionary.
